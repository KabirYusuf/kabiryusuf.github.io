Projects: AI Automation

Five production-style automation services built with Python, FastAPI and Claude. Each repo ships with tests that run offline against a mocked Claude client, plus Docker, GitHub Actions CI and a README covering its architecture and design decisions.

AI agent · Tool use

AI Meeting Actions

Upload a meeting transcript and a Claude agent turns it into action: it creates an owned, dated task for every commitment, schedules agreed follow-ups and writes the minutes.

  • Agentic tool-use loop: Claude decides when to call create_action_item, schedule_follow_up and finalize_summary
  • Invalid tool input goes back to the model as an error, so it corrects itself (e.g. "by Friday" becomes an ISO date)
  • Pushes tasks to Trello or any webhook; exports Markdown minutes and .ics calendar invites; parses Zoom/Teams VTT, SRT and DOCX

Document automation · Vision

AI Invoice Extractor

Upload invoices and receipts (PDF or photo). Claude extracts structured data, code checks it, and anything suspicious is flagged for human review before CSV export.

  • Claude vision with forced tool calls against a strict Pydantic schema, plus a validation-retry loop
  • Deterministic checks: line maths, subtotal + tax = total, date sanity, confidence threshold
  • Background processing, human correction endpoint, drag-and-drop UI

AI Support Triage

Watches a support inbox, contact form and API. Claude classifies, prioritises and routes each ticket, then drafts a reply grounded in a knowledge base for an agent to approve.

  • Jinja2 approval dashboard; optional auto-send for low-risk tickets
